## 2. Frontend Module Architecture (`frontend/src/modules/TensionMembers/`)

1. **Declarative Component Composition:**
   - Both `BoltedToEnd.jsx` and `WeldedToEnd.jsx` instantiate `<EngineeringModule>` with dedicated configuration schemas (`boltedToEndConfig.js` and `weldedToEndConfig.js`).
2. **Dynamic Section & Image Mapping (`boltedToEndConfig.js`):**
   - Section profile selection dynamically updates member section options (`getDynamicSectionList`), switching data sources between `angleList` and `channelList`.
   - `getSectionImage` cleanly updates cross-sectional diagram previews (Angles, Back-to-Back Angles, Star Angles, Channels).
3. **Parameter Serialization (`buildSubmissionParams`):**
   - Correctly maps UI inputs to standardized calculation keys (`KEY_SEC_PROFILE`, `KEY_SECSIZE`, `KEY_AXIAL`, `KEY_D`, `KEY_PLATETHK`). Handles "All" selection shortcuts by serializing full list arrays.

## 3. Backend Django API & ViewSet Routing (`backend/apps/modules/tension_member/`)

1. **REST Action Routing & Slug Normalization:**
   - `TensionMemberViewSet` maps REST endpoints dynamically:
     - `POST /api/modules/tension-member/{slug}/design/`
     - `GET /api/modules/tension-member/{slug}/options/`
     - `POST /api/modules/tension-member/{slug}/cad/`
     - `POST /api/modules/tension-member/{slug}/report/generate-initial/`
   - Method `_normalize_slug()` resolves legacy names (e.g. `'Tension-Member-Bolted-Design'`) to canonical slugs (`'bolted'`), maintaining backwards compatibility.
2. **Custom User Section Merging:**
   - In `views.py:options()`, standard catalog sections (`Angles`, `Channels`) are passed to `merge_user_sections_into_options(request, data)`, cleanly combining user-defined custom sections for authenticated users.

## 4. Input Validation & CAD Generation Adapters (`adapter.py`)

1. **Rigorous Validation Layer:**
   - `validate_input()` in `submodules/bolted/adapter.py` enforces explicit type checks for all 19 required parameter keys, ensuring numeric string convertibility (`int_able`, `float_able`) and array integrity before dispatching to `osdag_core`.
2. **OpenCASCADE 3D CAD & Manifest Export:**
   - `create_cad_model()` constructs BREP models using OpenCASCADE (`OCC`), writes individual BREP/STL shapes for Member, Plate, and Connector, and generates a `.parts.json` manifest.
